Crypto Investment Platform

A crypto investment platform I designed and built solo from scratch — investment plans, scheduled returns, referrals and a full admin panel.

Overview

This is the one I own end to end. I designed and developed the whole platform independently — schema, backend, frontend and admin — with Laravel, Tailwind CSS, MySQL, Redis, queues and Alpine.js.

Users deposit, choose an investment plan, and receive returns on a schedule; the platform handles the payout cycle, referrals and withdrawals, with an admin panel over the top.

Key Features

  • Investment plans — configurable tiers with their own rates, durations and minimums.
  • Scheduled returns — payouts accrue and settle automatically on a recurring cycle.
  • Wallet — deposits, balances and withdrawal requests.
  • Referral system — users earn from the people they bring in.
  • User dashboard — active investments, earnings and history at a glance.
  • Admin panel — plans, users, deposits and withdrawal approvals.

What I Did

  • Everything — this was a solo build: database design, backend, frontend and deployment.
  • Built the platform on Laravel with Tailwind CSS and Alpine.js on the front.
  • Implemented the recurring payout engine on queues and scheduled jobs.
  • Used Redis for caching and queue backing.
  • Deployed behind Nginx.

Challenges & How I Solved Them

1

Payouts that must run exactly once

A scheduled payout job that retries must not pay a user twice. Payouts are recorded per investment per cycle, so a re-run finds the cycle already settled and does nothing.

2

Money precision

Returns compound across cycles, so float rounding drifts. Balances and rates are handled with exact decimal arithmetic.

3

Doing it all alone

No backend/frontend split to hide behind — which forced a clean separation between the domain logic and the UI, and is the main reason the codebase stayed maintainable.
